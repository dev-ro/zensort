# YouTube Shelves, Topics, and Search Overhaul

## Data model and backend

- Move video display metadata to root `videos/{videoId}` only. Minimize `users/{uid}/likedVideos/{videoId}` to linking fields: `likedAt`, `syncedAt`.
- US categories only: resolve `categoryTitleUS` via YouTube `videoCategories.list` with `regionCode=US`, store on `videos`.
- Topics index: create `topics/{topicSlug}` docs with fields `{ name, slug, createdAt }` and subcollection `videos/{videoId}` containing minimal `{ createdAt }` (reverse reference). Maintain from Cloud Function during sync.
- Unliked videos: keep current `users/{uid}/unlikedVideos/{videoId}` writes; verify on sync and surface in UI by joining to `videos` metadata.
- Embeddings prompt: include `categoryTitleUS` and cleaned `topicTags` (derived from `topicCategories` URLs by taking last path segment, replacing `_` with space, Title Case, de-duped and truncated to N≈5). Store `topicTags` array on `videos` for reuse.
- Firestore rules: allow read on `topics/**` for authenticated users; writes restricted to server.

## Flutter data layer (repository)

- Refactor `YouTubeRepository` to stop reading display fields from `likedVideos`. Fetch `likedVideo` IDs in cursored batches, then fetch metadata from `videos` using chunked `in` queries (≤30 IDs per query). Merge into `LikedVideo` domain objects.
- Add `fetchAllLikedVideosBatched()` that iterates pages until completion, emitting partial results per page to support progressive search results.
- Add `fetchUnlikedVideos()` (IDs from `users/{uid}/unlikedVideos`) and join with `videos` metadata similarly.

## BLoC/state

- `YoutubeLoaded`: add `expandedShelfKey` (or index), `selectedTopic`, `availableTopics` (computed from loaded videos’ `topicTags`), and `isFullyLoaded` flag for all-liked pagination.
- Events: `ShelfExpansionChanged(key)`, `LoadAllVideosForSearch()`, `TopicFilterChanged(topic|null)`.
- Search: On first non-empty query or topic filter, dispatch `LoadAllVideosForSearch()`; filter in-memory by `title`, `channelName`, and `topicTags`. Continue loading remaining pages in background and update results as more arrive.
- Build shelves from all videos only when not in search/filter mode. Add an `Unliked Videos` shelf built from unliked join.

## UI

- `ExpandableVideoShelf`: convert to controlled component with `isExpanded` and `onExpansionChanged`. Remove internal expansion state.
- Only one shelf open: in `HomeScreen`, pass `isExpanded: shelf.key == state.expandedShelfKey`, and on expand set that key; closing it sets `expandedShelfKey = null`.
- Search mode UX: when `searchQuery != ''` or `selectedTopic != null`, hide shelves and show a `ResponsiveVideoGrid` of filtered videos. Above grid, render Material 3 `FilterChip`/`ChoiceChip` row of unique `availableTopics`.
- Ensure titles and channel names render using data from `videos` metadata, eliminating missing labels.
